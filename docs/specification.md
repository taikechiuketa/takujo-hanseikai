# 試作仕様

対局と設定はブラウザ内でグループごとに保存する。初期卓は「おためし卓」。画像と点数表は各10 MBまで。設定と添付はIndexedDBに保存し、対局データは従来のブラウザ保存を使う。点数表は画像またはPDF。ルール本文は閲覧用。クラウド同期と別端末共有は未実装。バックアップは対局データのみ。

画面・仕様変更時は画面説明と仕様書の該当箇所を同じ変更で更新する。

ヘッダー背景色は卓ごとの設定に保存する。未設定時は標準色を使い、文字色は背景の明るさに応じて白または黒を選ぶ。

## 製品版のデータ設計（開発中）

卓上反省会専用のSupabaseを使う。個人用たけチャートのDB、認証、ファイル保存領域、キーは利用しない。

ユーザーはグループを所有し、グループはセットを、セットは半荘を持つ。初期の書き込み権限は作成者のみ。グループ・セット・半荘の参照と変更はDBの行レベル権限で制御する。未ログインのユーザーに開放するテーブルはない。所有者や親への紐付けは作成後にクライアントから変更できない。

グループの作成時は選んだテンプレートの初期値を設定にコピーし、作成後はグループ単位で編集する。セット番号は同じグループ・日付の中で一意、半荘番号は同じセット内で一意。グループ削除は配下のセット・半荘も削除するため、削除UIは別途設計する。

スキーマは `supabase/migrations/20261109040000_group_management.sql`。この段階では本番DBに適用していない。ログイン画面、データ移行、公開共有、ファイル保存、課金は後続作業。
