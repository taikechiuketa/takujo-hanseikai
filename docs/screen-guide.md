# 画面説明

「新しいグループ」で卓を追加し、上部のプルダウンで切り替える。設定欄で卓名、12種類の配色、ロゴ、ルール本文、点数表を変更できる。配色は選択時にプレビューされる。ファイルを選択すると名前が表示され、設定を保存すると登録される。点数表の画像は画面に表示され、PDFはダウンロードできる。新しい卓のプレイヤーマスターは空で始まる。対局はスコアシートに入力し、通算成績・履歴から確認する。

「ヘッダーの背景色」で全体テーマとは別にヘッダーの色を選べる。選択時にプレビューされ、「設定を保存」で確定する。「標準色に戻す」も保存すると反映される。

## 製品版の予定

ログイン → グループ管理 → 対局・成績の順に開く。グループ管理では「新しいグループ」で名前を入力し、作成した卓を選ぶと対局画面に進む。ルール本文は作成後に設定画面で編集できる。公開中の試作は引き続き端末内保存で動く。

`account.html` でログイン・グループ管理ができる。メールで登録・ログインし、名前だけでグループを保存できる。グループ一覧から対局入力または卓の設定へ進めます。

グループ一覧の「対局を入力」で、既存のスコアシートと通算成績・履歴が開きます。「セットを保存」「セットを終了」などは従来の操作です。「セットを保存」「セットを終了」でDBに保存します。保存結果は画面上部に表示されます。入力途中の下書きはブラウザに自動保存されます。DB保存に失敗したときは「保存を再試行」が表示されます。履歴の取り込み・削除・バックアップ復元は、それぞれの操作でDBに保存します。卓の切り替えはグループ一覧で行います。「卓の設定」から名前・ロゴ・配色・ヘッダー色・ルール・点数表を変更できます。画像とPDFはこの端末のブラウザに保存されます。

「対局を入力」と「卓の設定」は別ページです。対局画面では登録済みのルール・点数表を参照できます。変更するときは「マイグループ」へ戻り、該当の卓の「卓の設定」を開きます。設定ページからは「対局を入力」で同じ卓に戻れます。

ログイン・マイグループは濃緑と真鍮色を基調とし、卓ごとのカードから対局入力と設定へ進めます。卓の設定では20種類の配色テーマを3色の見本から選べます。

プレイヤーマスターの登録・編集・削除・ランキング表示設定は、その操作でDBに保存する。失敗時は管理ダイアログに再試行ボタンが出る。

チップのマイナス入力は赤字で表示します。チップ合計が0枚でないセットを保存すると、合計枚数を示す確認が出ます。セット保存の結果はポップアップで確認できます。

「閲覧専用ページ」ではログイン中の所有者が保存済みの成績・履歴を参照できます。

ログイン後の「卓の設定」下部でグループを削除できます。確認欄に表示どおりの卓名を入力すると、卓の保存済み対局とプレイヤーマスターも削除されます。

対局・設定画面の「マイグループ」で一覧に戻れます。保存の状態は変更や保存結果があるときに表示されます。

マスターの保存エラーが出た場合も、セット保存でマスターがDBに確定すれば再試行表示が消えます。

「表示中の通算成績を書き出す」は、現在の期間・種目に合うプレイヤー名・対局数・累計ポイントをJSONで保存します。進行中の入力が含まれる場合は確認時に案内します。
