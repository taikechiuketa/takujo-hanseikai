# たけチャートUI改善の適用（2026-11-16）

## 対象と適用内容

卓上反省会のみ。たけチャートの本番アプリ・DBは変更しない。

| たけチャートの改善 | 卓上反省会での適用 |
| --- | --- |
| 明確なログイン入口 | 通常のindex入口は既存account.htmlへ案内。グループ選択と認証後の自動取得を維持 |
| 入力・成績・履歴・設定 | 卓の対局画面を4画面化。卓名・配色・ルール・公開設定は従来の設定ページへ連携 |
| ログイン・保存状態 | 対局画面のログイン中表示と、この端末からのログアウトを追加。DB保存済み・未保存・失敗の既存表示を維持 |
| サンプルを出さない | クラウドの新規卓は空の待機状態。通常入口から暗黙のローカル試作へ進まない。既存データの名前による自動削除もしない |
| 対局日・連番の編集 | 進行中・過去セットで編集。重複を拒否し内部archiveIdを維持。共有URLも維持 |
| 名前・半荘列の固定 | 入力・履歴・セット共有に内部スクロールを導入。半荘追加で内部末尾へ移動 |
| 着順回数・割合 | 履歴とセット共有に1〜4着の回数・割合を追加。抜け・未入力は母数から除く |
| 通算期間とR推移期間 | 管理側で独立したフィルターに分離。現在Rとそこから開く個人成績は全期間 |
| 公開ランキングの期間 | 全期間RPC応答から現在Rを取得。月別通算と分離。R推移は公開許可時だけ独立した期間で表示 |
| 復旧・未確定編集 | アカウント＋卓別に復旧コピーを保存・出力・端末復元。編集中の履歴も保護・再開 |

## データと権限

スキーマ・RLS・SQL RPC・テーブル・既存データ形式は変更しない。所有者確認、卓のリビジョン、保存のリクエストID、安定したセットID、トランザクション保存を維持する。公開される指標は既存APIの許可項目だけを描画する。月別と全期間の公開設定が異なる応答を受けた場合は混在表示せず失敗として扱う。

管理用・未送信用・復旧用のデータは公開リポジトリに含めない。復旧コピーに認証トークンやパスワードを含めない。復旧のscopeは所有者ID＋卓IDで分ける。同じブラウザ上の端末保存であり、暗号化保管や端末故障への別媒体バックアップではない。ファイルへの書き出しも提供する。

公開作業で本番DBへの書き込みは行わない。実アカウントの最新DBを開発環境へ完全バックアップしたとは扱わない。改修版の認証付き読み込み時に、revision照合済みの保存データを端末へ保護し、保護できなければ作業を止める。
